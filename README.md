# Final Project

## Emotion Detector

Repository: `oaqjp-final-project-emb-ai`

This final project's objective is to develop an AI-based web application using Python, the Watson NLP emotion detection service, and Flask. The application will analyse text for anger, disgust, fear, joy, and sadness, and identify the dominant emotion.

### Project tasks

1. Clone the project repository.
2. Implement emotion detection using Watson NLP.
3. Format emotion scores and the dominant emotion.
4. Package the application as `EmotionDetection`.
5. Run unit tests.
6. Deploy the web application using Flask.
7. Handle invalid and blank input.
8. Run static code analysis.
